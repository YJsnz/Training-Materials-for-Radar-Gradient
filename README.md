## 这个仓库是什么

雷达站的工作不是"会调库"就够了。你要在一台 Linux 机器上，把下面这条链路串起来，并且让另一个人按你的文档能在他的电脑上复现：

```text
相机取流 → 车体检测 → 装甲板识别 → 多目标跟踪
        → 像素→场地坐标（标定/掩膜） → 输出目标信息
```

仓库里的三份文档分别回答三个不同的问题：

| 文档 | 回答的问题 | 什么时候读 |
| --- | --- | --- |
| [项目开发手册.md](./项目开发手册.md) | **做之前我必须会什么？**（Linux、环境、Git、AI、26 赛季工程） | 最开始，正式训练前 3 天 |
| [算法侧培训计划.md](./算法侧培训计划.md) | **第几周做什么、做到什么程度算过？**（六周项目制培养方案） | 读完手册后，每周开工前 |
| [AI使用小结_26年8月实训做分享.md](./AI使用小结_26年8月实训做分享.md) | **怎么让 AI 真正提速，而不是替你思考？**（概念 + 工具 + 踩坑经验） | 全程，建议先通读一遍 |

`docs/` 目录存放上述文档引用的图片素材。

## 使用须知

- **先跑通离线视频，再碰相机。** 环境阻塞（没相机、没 GPU、没网）不是停下来的理由。
- **AI 生成的代码，没在本机跑过、没看过 diff，就不许提交。**
- 比赛代码、模型文件、标定数据**不要**上传到公共仓库或网盘分享链接；大文件也不要塞进 Git。
- 本仓库只用于培训与学习，训练代码与比赛代码保持隔离。
